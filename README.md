# grasp_fabrics


## Requirements
```bash
poetry install
```


## Build
1. Fabrics shared library (C++)
```bash
git clone git@github.com:TomasMerva/grasp_fabrics.git
cd grasp_fabrics && mkdir build
cd build
cmake ..
make
```
2. Fabrics Client (python)
```bash
cd grasp_fabrics
poetry install
```

## Use
1. Using autogenerated fabrics controller
```bash
python examples/rollouts/example_fabrics_driver.py
```
2. Using rollouts
```bash
python examples/rollouts/example_dinova_rollout.py
```

## Warnings
1. If you generate a new fabrics controller, you need to rebuild shraed library in the `build` folder.
